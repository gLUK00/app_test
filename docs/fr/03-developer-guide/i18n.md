# Internationalisation (i18n)

TestGyver supporte plusieurs langues en utilisant **Flask-Babel**.

## Langues Supportées
*   Anglais (en) - Défaut
*   Français (fr)
*   Espagnol (es)
*   Allemand (de)
*   Italien (it)
*   Japonais (ja)
*   Chinois (zh)

## Workflow

### 1. Marquer les Chaînes pour Traduction

Dans Python (`.py`) :
```python
from flask_babel import _
error_message = _("Une erreur est survenue")
```

Dans les Templates (`.html`) :
```html
<h1>{{ _('Bienvenue sur TestGyver') }}</h1>
```

### 2. Extraire les Messages

Extraire toutes les chaînes marquées dans un fichier template (`messages.pot`).
```bash
pybabel extract -F babel.cfg -k _l -o messages.pot .
```

### 3. Mettre à jour les Traductions

Mettre à jour les fichiers de langue existants (`.po`) avec les nouvelles chaînes.
```bash
pybabel update -i messages.pot -d translations
```

### 4. Traduire

Éditer les fichiers `.po` dans `translations/<lang>/LC_MESSAGES/messages.po` en utilisant un éditeur de texte ou un outil comme Poedit.

### 5. Compiler

Compiler les traductions en fichiers binaires `.mo` pour l'efficacité.
```bash
pybabel compile -d translations
```

## Ajouter une Nouvelle Langue

1.  Initialiser le catalogue de la nouvelle langue :
    ```bash
    pybabel init -i messages.pot -d translations -l <code_langue>
    ```
2.  Suivre les étapes 4 et 5 ci-dessus.
