# Premiers Pas

Bienvenue sur TestGyver ! Ce guide vous aidera à naviguer dans l'application pour la première fois.

## Connexion

Accédez à l'application via l'URL configurée (par défaut : `http://localhost:5000`).
Vous serez accueilli par la page de connexion mettant en vedette notre mascotte.

*   **Identifiants Admin par Défaut** (si initialisés) :
    *   Email : `admin@test.com`
    *   Mot de passe : `Password123`

## Aperçu du Tableau de Bord

Une fois connecté, vous arrivez sur le **Tableau de Bord** (Dashboard).

*   **Liste des Campagnes** : La zone centrale affichant toutes vos campagnes de test.
*   **Barre de Navigation** :
    *   **Dashboard** : Retour à l'accueil.
    *   **Admin** (Admin uniquement) : Accès à la gestion des Utilisateurs et des Variables.
    *   **Sélecteur de Langue** : Basculer entre les langues disponibles.
    *   **Déconnexion** : Terminer votre session.
*   **Pied de page** : Affiche la version actuelle de l'application et un lien vers la documentation API Swagger.

## Premières Étapes

1.  **Créer une Campagne** : Cliquez sur le bouton "Ajouter une Campagne".
2.  **Ajouter des Tests** : Entrez les détails de la campagne et commencez à ajouter des tests.
3.  **Exécuter** : Lancez votre campagne et observez les résultats en temps réel.
