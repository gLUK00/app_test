# Prerrequisitos

Antes de instalar TestGyver, asegúrate de que tu sistema cumpla con los siguientes requisitos.

## Requisitos del Sistema

*   **Sistema Operativo**: Linux, macOS o Windows (se recomienda WSL2).
*   **Memoria**: Recomendado mínimo 2GB RAM.
*   **Espacio en Disco**: 500MB para el código de la aplicación y dependencias.

## Dependencias de Software

### Python
TestGyver está construido con Python. Necesitas **Python 3.11** o superior.
*   Verificar versión: `python --version`

### MongoDB
La aplicación usa MongoDB como base de datos principal. Necesitas **MongoDB 6.0** o superior.
*   Puedes instalarlo localmente o usar un contenedor Docker.
*   [Descargar MongoDB Community Server](https://www.mongodb.com/try/download/community)

### Git
Requerido para clonar el repositorio.
*   [Descargar Git](https://git-scm.com/downloads)

### Opcional
*   **Docker y Docker Compose**: Recomendados para despliegue en contenedores y entornos de prueba (servidores FTP, SFTP para pruebas).
