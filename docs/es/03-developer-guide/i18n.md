# Internacionalización (i18n)

TestGyver soporta múltiples idiomas usando **Flask-Babel**.

## Idiomas Soportados
*   Inglés (en) - Por defecto
*   Francés (fr)
*   Español (es)
*   Alemán (de)
*   Italiano (it)
*   Japonés (ja)
*   Chino (zh)

## Flujo de Trabajo

### 1. Marcar Cadenas para Traducción

En Python (`.py`):
```python
from flask_babel import _
error_message = _("An error occurred")
```

En Plantillas (`.html`):
```html
<h1>{{ _('Welcome to TestGyver') }}</h1>
```

### 2. Extraer Mensajes

Extrae las cadenas a `messages.pot`.
```bash
pybabel extract -F babel.cfg -k _l -o messages.pot .
```

### 3. Actualizar Traducciones

Actualiza los `.po` existentes.
```bash
pybabel update -i messages.pot -d translations
```

### 4. Traducir

Edita los `.po` en `translations/<lang>/LC_MESSAGES/messages.po`.

### 5. Compilar

Compila a `.mo` binarios.
```bash
pybabel compile -d translations
```

## Añadir un Nuevo Idioma

1.  Inicializa el catálogo:
    ```bash
    pybabel init -i messages.pot -d translations -l <lang_code>
    ```
2.  Sigue los pasos 4 y 5.
