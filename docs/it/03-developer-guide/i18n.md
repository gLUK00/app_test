# Internazionalizzazione (i18n)

TestGyver supporta più lingue con **Flask-Babel**.

## Lingue Supportate
*   Inglese (en) - default
*   Francese (fr)
*   Spagnolo (es)
*   Tedesco (de)
*   Italiano (it)
*   Giapponese (ja)
*   Cinese (zh)

## Flusso di lavoro

### 1. Marcare le stringhe

Python (`.py`):
```python
from flask_babel import _
error_message = _("An error occurred")
```

Template (`.html`):
```html
<h1>{{ _('Welcome to TestGyver') }}</h1>
```

### 2. Estrarre
```bash
pybabel extract -F babel.cfg -k _l -o messages.pot .
```

### 3. Aggiornare
```bash
pybabel update -i messages.pot -d translations
```

### 4. Tradurre
Modifica i `.po` in `translations/<lang>/LC_MESSAGES/messages.po`.

### 5. Compilare
```bash
pybabel compile -d translations
```

## Aggiungere una nuova lingua

```bash
pybabel init -i messages.pot -d translations -l <lang_code>
```
Poi passi 4 e 5.
