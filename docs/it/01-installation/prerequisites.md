# Prerequisiti

Prima di installare TestGyver, verifica che il tuo sistema rispetti questi requisiti.

## Requisiti di Sistema

*   **Sistema Operativo**: Linux, macOS o Windows (consigliato WSL2).
*   **Memoria**: Minimo consigliato 2GB RAM.
*   **Spazio Disco**: 500MB per codice e dipendenze.

## Dipendenze Software

### Python
TestGyver usa Python. Serve **Python 3.11** o superiore.
*   Controlla versione: `python --version`

### MongoDB
Database principale. Serve **MongoDB 6.0** o superiore.
*   Installazione locale o via Docker.
*   [Scarica MongoDB Community Server](https://www.mongodb.com/try/download/community)

### Git
Necessario per clonare il repository.
*   [Scarica Git](https://git-scm.com/downloads)

### Opzionale
*   **Docker & Docker Compose**: Consigliati per deployment containerizzato e ambienti di test (FTP/SFTP).
