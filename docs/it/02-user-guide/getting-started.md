# Per Iniziare

Benvenuto in TestGyver! Questa guida ti accompagna nel primo utilizzo.

## Login

Apri l'URL configurato (default: `http://localhost:5000`). Vedrai la pagina di login con la mascotte.

*   **Admin di default** (se inizializzato):
    *   Email: `admin@test.com`
    *   Password: `Password123`

> **[SCREENSHOT]** Schermata di login con mascotte pixel art.

## Panoramica Dashboard

Dopo il login arrivi al **Dashboard**.

> **[SCREENSHOT]** Dashboard con lista campagne e navbar.

*   **Lista Campagne**: Elenco centrale delle campagne.
*   **Navigazione**:
    *   **Dashboard**: Torna alla home.
    *   **Admin** (solo admin): Gestione Utenti e Variabili.
    *   **Lingua**: Cambia lingua.
    *   **Logout**: Termina sessione.
*   **Footer**: Versione app e link API Swagger.

## Primi Passi

1.  **Crea una Campagna**: clic su "Add Campaign".
2.  **Aggiungi Test**: compila e aggiungi test.
3.  **Esegui**: lancia la campagna e guarda i risultati live.
