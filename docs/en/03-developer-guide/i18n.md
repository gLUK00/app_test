# Internationalization (i18n)

TestGyver supports multiple languages using **Flask-Babel**.

## Supported Languages
*   English (en) - Default
*   French (fr)
*   Spanish (es)
*   German (de)
*   Italian (it)
*   Japanese (ja)
*   Chinese (zh)

## Workflow

### 1. Mark Strings for Translation

In Python (`.py`):
```python
from flask_babel import _
error_message = _("An error occurred")
```

In Templates (`.html`):
```html
<h1>{{ _('Welcome to TestGyver') }}</h1>
```

### 2. Extract Messages

Extract all marked strings into a template file (`messages.pot`).
```bash
pybabel extract -F babel.cfg -k _l -o messages.pot .
```

### 3. Update Translations

Update existing language files (`.po`) with the new strings.
```bash
pybabel update -i messages.pot -d translations
```

### 4. Translate

Edit the `.po` files in `translations/<lang>/LC_MESSAGES/messages.po` using a text editor or a tool like Poedit.

### 5. Compile

Compile the translations into binary `.mo` files for efficiency.
```bash
pybabel compile -d translations
```

## Adding a New Language

1.  Initialize the new language catalog:
    ```bash
    pybabel init -i messages.pot -d translations -l <lang_code>
    ```
2.  Follow steps 4 and 5 above.
