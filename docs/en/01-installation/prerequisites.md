# Prerequisites

Before installing TestGyver, ensure your system meets the following requirements.

## System Requirements

*   **Operating System**: Linux, macOS, or Windows (WSL2 recommended).
*   **Memory**: Minimum 2GB RAM recommended.
*   **Disk Space**: 500MB for application code and dependencies.

## Software Dependencies

### Python
TestGyver is built with Python. You need **Python 3.11** or higher.
*   Check version: `python --version`

### MongoDB
The application uses MongoDB as its primary database. You need **MongoDB 6.0** or higher.
*   You can install it locally or use a Docker container.
*   [Download MongoDB Community Server](https://www.mongodb.com/try/download/community)

### Git
Required to clone the repository.
*   [Download Git](https://git-scm.com/downloads)

### Optional
*   **Docker & Docker Compose**: Recommended for containerized deployment and running test environments (FTP, SFTP servers for testing).
