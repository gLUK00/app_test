# Getting Started

Welcome to TestGyver! This guide will help you navigate the application for the first time.

## Login

Access the application at the configured URL (default: `http://localhost:5000`).
You will be greeted by the login page featuring our mascot.

*   **Default Admin Credentials** (if initialized):
    *   Email: `admin@test.com`
    *   Password: `Password123`

> **[SCREENSHOT]** Login page with the MacGyver pixel art mascot.

## Dashboard Overview

Once logged in, you arrive at the **Dashboard**.

> **[SCREENSHOT]** Dashboard view showing the list of campaigns and the navigation bar.

*   **Campaigns List**: The central area showing all your test campaigns.
*   **Navigation Bar**:
    *   **Dashboard**: Return to home.
    *   **Admin** (Admin only): Access User and Variable management.
    *   **Language Selector**: Switch between available languages.
    *   **Logout**: End your session.
*   **Footer**: Displays the current application version and a link to the API Swagger documentation.

## First Steps

1.  **Create a Campaign**: Click the "Add Campaign" button.
2.  **Add Tests**: Enter the campaign details and start adding tests.
3.  **Execute**: Launch your campaign and watch the results in real-time.
