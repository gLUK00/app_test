# Internationalisierung (i18n)

TestGyver unterstützt mehrere Sprachen mit **Flask-Babel**.

## Unterstützte Sprachen
*   Englisch (en) - Default
*   Französisch (fr)
*   Spanisch (es)
*   Deutsch (de)
*   Italienisch (it)
*   Japanisch (ja)
*   Chinesisch (zh)

## Workflow

### 1. Strings markieren

Python (`.py`):
```python
from flask_babel import _
error_message = _("An error occurred")
```

Templates (`.html`):
```html
<h1>{{ _('Welcome to TestGyver') }}</h1>
```

### 2. Nachrichten extrahieren

```bash
pybabel extract -F babel.cfg -k _l -o messages.pot .
```

### 3. Übersetzungen aktualisieren

```bash
pybabel update -i messages.pot -d translations
```

### 4. Übersetzen

`.po` in `translations/<lang>/LC_MESSAGES/messages.po` bearbeiten.

### 5. Kompilieren

```bash
pybabel compile -d translations
```

## Neue Sprache hinzufügen

```bash
pybabel init -i messages.pot -d translations -l <lang_code>
```
Dann Schritte 4 und 5.
