# Erste Schritte

Willkommen bei TestGyver! Diese Anleitung hilft dir beim ersten Einstieg.

## Login

Rufe die konfigurierte URL auf (Standard: `http://localhost:8080`). Du siehst die Login-Seite mit dem Maskottchen.

*   **Standard-Admin** (falls initialisiert):
    *   Email: `admin@test.com`
    *   Passwort: `Password123`

![Login-Seite](../../assets/login_page.png)
> Login-Seite mit Pixel-Art-Maskottchen.

## Dashboard-Übersicht

Nach dem Login landest du im **Dashboard**.

![Dashboard](../../assets/dashboard.png)
> Dashboard mit Kampagnenliste und Navigation.

*   **Kampagnenliste**: Zentrale Übersicht aller Kampagnen.
*   **Navigation**:
    *   **Dashboard**: Zur Startseite.
    *   **Admin** (nur Admin): Benutzer- und Variablenverwaltung.
    *   **Sprachauswahl**: Sprache wechseln.
    *   **Logout**: Sitzung beenden.
*   **Footer**: Aktuelle Version und Link zur API Swagger.

## Erste Schritte

1.  **Kampagne erstellen**: Klicke "Add Campaign".
2.  **Tests hinzufügen**: Daten eingeben und Tests ergänzen.
3.  **Ausführen**: Kampagne starten und Ergebnisse live verfolgen.
