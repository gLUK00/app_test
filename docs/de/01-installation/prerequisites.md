# Voraussetzungen

Bevor du TestGyver installierst, stelle sicher, dass dein System die folgenden Anforderungen erfüllt.

## Systemanforderungen

*   **Betriebssystem**: Linux, macOS oder Windows (WSL2 empfohlen).
*   **Speicher**: Mindestens 2GB RAM empfohlen.
*   **Platzbedarf**: 500MB für Code und Abhängigkeiten.

## Software-Abhängigkeiten

### Python
TestGyver basiert auf Python. Du brauchst **Python 3.11** oder höher.
*   Version prüfen: `python --version`

### MongoDB
Die Anwendung nutzt MongoDB als Hauptdatenbank. **MongoDB 6.0** oder höher.
*   Lokal installieren oder per Docker.
*   [MongoDB Community Server herunterladen](https://www.mongodb.com/try/download/community)

### Git
Wird benötigt, um das Repository zu klonen.
*   [Git herunterladen](https://git-scm.com/downloads)

### Optional
*   **Docker & Docker Compose**: Empfohlen für containerisierten Betrieb und Test-Umgebungen (FTP/SFTP).
