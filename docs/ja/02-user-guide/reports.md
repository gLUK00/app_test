# レポートとモニタリング

レポートは実行履歴を詳細に記録します。

## レポート閲覧

*   **Dashboard**: "Reports" タブ（あれば）またはキャンペーン経由。
*   **キャンペーン内**: "Reports" セクションに全実行が表示。

## レポート詳細

クリックで詳細ビューへ：

> **[SCREENSHOT]** ステータスとテスト一覧。

### ヘッダー
*   **Status**: Success / Failure / Running
*   **Progress**: 進捗率
*   **Environment**: 使用環境
*   **Timings**: 開始・終了・所要時間

### テスト結果
全テストの一覧。
*   **ステータスアイコン**: ✅ 合格 / ❌ 失敗
*   **ログ**: 展開して詳細表示
    *   送受信データ
    *   アクションごとの時間
    *   エラーメッセージ

## リアルタイム更新
WebSocket により自動更新。リロード不要。
