# キャンペーン管理

**キャンペーン** はテストをまとめる単位です。

## キャンペーンを作成

1.  Dashboard で **Add Campaign** をクリック。
2.  入力:
    *   **Name**: 一意の名前
    *   **Description**: 任意
3.  保存すると詳細ページへ遷移。

> **[SCREENSHOT]** 「Add Campaign」フォーム。

## 詳細ビュー

コントロールセンター。

> **[SCREENSHOT]** Information / Files / Tests セクション。

### 1. Information
メタデータ表示。編集・削除可能。

### 2. ファイル管理
キャンペーン関連ファイルを管理。
*   **アップロード**: workdir に追加。
*   **リネーム/削除**。
*   **ダウンロード**。

テストから `{{test.files_dir}}` で参照可能。

### 3. テスト一覧
全テストを表示。
*   **並べ替え**: 上下矢印。
*   **Add Test**: 新規テスト。
*   **Execute**: 単体実行。

## キャンペーン実行

1.  **Execute Campaign** をクリック。
2.  設定:
    *   **Name**: 自動生成（例 "March 2023"）、編集可。
    *   **Environment**: 環境を選択。
    *   **Stop on Failure**: 最初の失敗で停止。
3.  実行（バックグラウンド）。

> **[SCREENSHOT]** 環境選択付きモーダル。

### リアルタイム監視
進捗バーとステータス。
*   **青**: 実行中
*   **緑**: 成功
*   **赤**: 失敗

レポートをクリックしてログを表示。
