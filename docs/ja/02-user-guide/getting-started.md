# はじめに

ようこそ TestGyver へ！初回利用のためのガイドです。

## ログイン

設定した URL（デフォルト `http://localhost:5000`）にアクセスするとログイン画面が表示されます。

*   **デフォルト管理者**（初期化済みの場合）
    *   Email: `admin@test.com`
    *   Password: `Password123`

> **[SCREENSHOT]** マスコット付きログイン画面。

## ダッシュボード概要

ログイン後、**Dashboard** に遷移します。

> **[SCREENSHOT]** キャンペーン一覧とナビ。

*   **キャンペーン一覧**: すべてのテストキャンペーン。
*   **ナビバー**:
    *   **Dashboard**: ホームへ
    *   **Admin**（管理者のみ）: ユーザー/変数管理
    *   **言語切替**
    *   **Logout**
*   **フッター**: バージョンと API Swagger リンク。

## 最初のステップ

1.  **キャンペーン作成**: 「Add Campaign」をクリック。
2.  **テスト追加**: 情報を入力しテストを追加。
3.  **実行**: キャンペーンを開始しリアルタイムで結果を見る。
