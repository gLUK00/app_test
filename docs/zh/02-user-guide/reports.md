# 报告与监控

报告提供执行历史和详情。

## 访问报告

*   **Dashboard**："Reports" 标签（若有）或通过活动进入。
*   **活动内**："Reports" 列出所有执行。

## 报告详情

点击打开详情页：

> **[SCREENSHOT]** 报告页，含状态和测试列表。

### 头部
*   **状态**：Success / Failure / Running
*   **进度**：完成百分比
*   **环境**：执行环境
*   **时间**：开始、结束、总时长

### 测试结果
列出所有测试。
*   **状态图标**：✅ 通过 / ❌ 失败
*   **日志**：展开查看
    *   发送/接收数据
    *   每个动作耗时
    *   错误信息

## 实时更新
使用 WebSocket 实时刷新，无需手动刷新页面。
