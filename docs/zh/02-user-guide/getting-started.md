# 入门指南

欢迎使用 TestGyver！本指南帮助你首次上手。

## 登录

访问配置的地址（默认 `http://localhost:5000`），可见登录页和吉祥物。

*   **默认管理员**（若已初始化）：
    *   Email: `admin@test.com`
    *   密码: `Password123`

![登录页](../../assets/login_page.png)
> 登录页（像素风吉祥物）。

## 仪表盘概览

登录后进入 **Dashboard**。

![仪表盘](../../assets/dashboard.png)
> 仪表盘、活动列表和导航栏。

*   **活动列表**：显示所有测试活动。
*   **导航栏**：
    *   **Dashboard** 返回主页
    *   **Admin**（仅管理员）用户与变量管理
    *   **语言切换**
    *   **Logout** 退出
*   **页脚**：当前版本与 API Swagger 链接。

## 第一步

1.  **创建活动**：点击 “Add Campaign”。
2.  **添加测试**：填写信息并添加测试。
3.  **执行**：启动活动，实时查看结果。
