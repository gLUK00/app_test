# 前置条件

安装 TestGyver 之前，请确认系统满足以下要求。

## 系统要求

*   **操作系统**：Linux、macOS 或 Windows（推荐 WSL2）。
*   **内存**：建议至少 2GB RAM。
*   **磁盘空间**：约 500MB（代码与依赖）。

## 软件依赖

### Python
TestGyver 使用 Python，需要 **Python 3.11** 及以上。
*   检查版本：`python --version`

### MongoDB
主数据库，需要 **MongoDB 6.0** 及以上。
*   可本地安装或使用 Docker。
*   [下载 MongoDB Community Server](https://www.mongodb.com/try/download/community)

### Git
用于克隆仓库。
*   [下载 Git](https://git-scm.com/downloads)

### 可选
*   **Docker & Docker Compose**：推荐用于容器化部署和测试环境（FTP/SFTP）。
